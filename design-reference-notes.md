# Design Reference Notes

The component review informed patterns rather than supplying a template. The SEOSignal implementation will use a deliberately asymmetric, text-forward hero with broad negative space, a monochrome emerald field, and thin structural rules rather than image-led layouts, gradients, or decorative effects.

The qualification signal matrix will use a low-density table treatment: a restrained header, generous row height, fine sage dividers, left-aligned evidence, and compact text-led assessment indicators. No external 21st.dev component will be copied directly; the application will use an original design system tailored to SEOSignal.
