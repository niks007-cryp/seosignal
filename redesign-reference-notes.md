# Radical Redesign Reference Notes

The redesigned SEOSignal experience will use the studied sites only as high-level compositional references. Linear demonstrates how a product surface can become the visual focal point while supporting dense information with measured negative space. Vercel demonstrates how a strong central visual anchor, a sparse supporting narrative, and fine structural geometry can create hierarchy without decorative overload.

The original SEOSignal direction will translate those general patterns into a distinct, emerald analytical instrument: an asymmetric hero, a constructed organic-search signal map, an overlapping qualification console, restrained grid and hairline details, and report-specific data visualizations. No visual layout, code, copy, or proprietary asset will be copied from the reference sites.
